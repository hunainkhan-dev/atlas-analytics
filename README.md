# Atlas — SaaS Analytics Dashboard

Opinionated real-time analytics dashboard concept. React + Vite + Tailwind + Framer Motion.

**Highlights:** sidebar app shell, hero MRR metric with an animated SVG area chart (path drawn from data), stat cards with deltas, a real cohort-retention heatmap, an AI "Weekly Read" panel, and a live activity feed.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Portfolio case study for **Hunain**. All figures are mock data.
