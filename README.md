An opinionated **real-time SaaS analytics dashboard** UI — the product surface of a modern data app, built front-end-first.

### 🔗 [**View Live Demo →**](https://axiomwebbuilder.com/demos/atlas-analytics/)

---

## ✨ Highlights

- **Sidebar app shell** with a real dashboard layout
- Hero MRR metric with an **animated SVG area chart** (path drawn from data)
- Stat cards with trend deltas
- A real **cohort-retention heatmap**
- **AI Weekly Read** insight panel + live activity feed

## 🧱 Tech stack

| Layer | Tech |
|-------|------|
| Framework | React 18 + Vite |
| Styling | Tailwind CSS |
| Motion | Framer Motion + GSAP |
| Charts | Hand-built SVG (data-driven) |
| Icons | Lucide |

## 🚀 Run locally

```bash
npm install
npm run dev
npm run build
```
